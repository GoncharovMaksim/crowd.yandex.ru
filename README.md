# 🏆 Международный Васюкинский Шахматный Клуб

Адаптивный Pixel-Perfect лендинг по макету из Figma для Международного Васюкинского турнира по шахматам с участием великих гроссмейстеров.

Сайт разработан с соблюдением принципа Pixel Perfect, адаптирован под все типы экранов (десктоп, планшет, мобильные телефоны) и снабжен кастомными интерактивными компонентами на чистом JavaScript без внешних библиотек и фреймворков.

---

## ✨ Ключевые особенности

### 🛡️ 1. Pixel-Perfect и Адаптивность
* Полная адаптивность от **320px до 1920px**.
* Отсутствие горизонтального скролла на любом разрешении.
* Адаптивная типографика с использованием Google Fonts: `Golos Text` (основной), `Merriweather` (акцентные заголовки), `Montserrat` (имена участников).
* Поддержка Retina-экранов и высокая плотность пикселей.

### 🏃‍♂️ 2. Бесконечная бегущая строка (CSS Marquee)
* Реализована на чистом CSS с использованием GPU-ускорения (`transform: translate3d`).
* Максимально плавный скролл с частотой **60fps+** даже на мобильных устройствах.
* Не дублирует контент в DOM структуре, обеспечивая высокую производительность.

### 🧩 3. Асимметричная сетка этапов преображения (CSS Grid / Flexbox)
* **На десктопе**: Реализована сложная асимметричная сетка с использованием **CSS Grid**, точно соответствующая макету (вертикальный спан 3-го этапа, горизонтальный спан 7-го этапа с вылетающим самолетом).
* **На мобильном**: Сетка скрывается и плавно перестраивается в карусель-слайдер из **5 слайдов**.
* Карусель этапов имеет ограниченную прокрутку (не бесконечная), кнопки управления переходят в состояние `disabled` на граничных слайдах, активный слайд подсвечивается точками пагинации.

### 🔄 4. Бесконечная циклическая карусель участников (Infinite Loop Carousel)
* Полностью loop-карусель (при достижении конца или начала трека переход происходит бесшовно и плавно).
* Автоматическое перелистывание каждые **4 секунды**.
* Пауза автопроигрывания при наведении курсора мыши или таче пальцем.
* Динамическая адаптивность колонок: **3 карточки на десктопе**, **2 на планшете**, **1 на мобильном**.
* Поддержка **жестов свайпа** (swipe left/right) на тач-экранах.
* Интегрированные счетчики положения слайда (синхронно обновляются на мобильной и десктопной версиях).

## 🛠️ Технологический стек

* **Разметка**: Семантический HTML5
* **Стилизация**: Vanilla CSS (переменные, Grid Layout, Flexbox, Keyframes-анимации)
* **Интерактив**: Pure JavaScript (без зависимостей)
* **Сборка и HMR**: Vite

## 🚀 Быстрый старт (Локальный запуск)

Для запуска проекта локально на компьютере выполните следующие шаги:

### 1. Установка зависимостей
Убедитесь, что у вас установлен Node.js. Склонируйте репозиторий и установите Vite:
```bash
npm install
```

### 2. Запуск в режиме разработки (Dev Server)
Запустите локальный сервер разработки:
```bash
npm run dev
```
После запуска проект будет доступен по адресу: `http://localhost:5173/`

### 3. Сборка для продакшна (Production Build)
Соберите оптимизированную версию проекта в папку `dist`:
```bash
npm run build
```
